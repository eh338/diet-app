饮食记录 · 使用说明
==============================

零、你现在用 GitHub Pages 更新（eh338.github.io/diet-app）
1. 解压「饮食记录-app.zip」，确认 index.html 在文件夹根目录（不要再套一层子文件夹）。
2. 打开仓库 eh338/diet-app → Add file → Upload files，把文件夹里的全部文件拖进去覆盖，然后 Commit changes。
3. 等 1–2 分钟，手机刷新页面。若仍是旧界面，把页面彻底关掉重开，或在浏览器设置里清一次该站点的缓存。
4. 同一个域名下 localStorage 不变，历史记录、体重、目标、自建食物都不会丢。
5. 不要删除 icon-192.png / icon-512.png，否则已添加到桌面的图标可能变成白块。

一、三步上线（Netlify Drop，免费）
1. 解压「饮食记录-app.zip」，得到一个文件夹。文件夹里应直接看到 index.html、app.js、data.js、pinyin.js、zxing.min.js、manifest.json、sw.js 和两个图标，不要再套一层子文件夹。
2. 电脑浏览器打开 https://app.netlify.com/drop ，把整个文件夹拖进去。
3. 等 10–30 秒，页面给出一个 https://xxx.netlify.app 地址。手机浏览器打开它，用菜单里的「添加到主屏幕 / 安装应用」。
建议顺手点页面右上角注册并认领这个站点（Claim site）。未登录的匿名站点可能被平台回收；认领后长期保留，免费额度足够个人使用。

二、换地址后的数据迁移（顺序很重要）
1. 先在旧地址打开应用 → 「我的」→「导出 JSON 备份」。
2. 再打开新地址 → 「我的」→「导入还原」，选择刚才的 JSON 文件。
3. 如果扫码存了包装图，需要连图一起搬：旧机点「含图片备份」，新机导入同一个文件即可（图片存 IndexedDB，文件会明显变大）。
4. 旧地址的桌面图标删掉，重新添加新地址的图标。
5. 数据存在浏览器的 localStorage，按域名隔离：旧域名的数据不会自动出现在新域名，必须走上面的导出/导入。

三、本版新增
- 食物库 1100+ 条（内置 1124 条：中国食物成分表第 6 版 1020 条、USDA 38 条、估算 66 条），可用中文名、别名、拼音首字母（如 jxr → 鸡胸肉）和分类筛选。
- 底部导航新增「消耗」：按运动种类/时长/强度，用你的体重和 BMR 算总消耗与净额外消耗；结果一键写进当天运动记录，并计入「今天」页的还可吃额度。
- 力量训练新增「负重引体向上」：正手/反手、组数×次数、外加负重（负值=助力）、每次垂直位移可调；按机械功 ÷ 做功效率（20–25%，取 22.5%）估算，界面明确标注为估算，并显示净额外/总消耗/抵消多少 kcal。
- 扫码：点「食物」页右上角 📷。安卓 Chrome 用原生 BarcodeDetector；iOS Safari 自动使用随包里自带的 ZXing（不依赖 CDN，离线也能解码）。
- 扫码成功会抓一张包装静帧，并尝试下载 Open Food Facts 封面图；压缩后存 IndexedDB（不占 localStorage）。记录列表有缩略图，详情看大图与条码。
- 扫到的商品自动进入「我的扫码」，按条码去重：同一条码再扫会更新原条目，不新增副本。内置权威条目不会被覆盖，自建条目可编辑/删除。
- 图片占用：我的 → 扫码包装图 → 查看占用 / 清理旧图片（保留最近 30 张，正在使用的图不会删）。

四、纯静态托管下不能用 / 受限的功能（如实说明）
- 扫码查条码：需要联网访问 Open Food Facts（https）。站点是 https、给了摄像头权限即可；iOS Safari 没有 BarcodeDetector，会自动用本地 ZXing。
- 断网时：条码查询不可用；搜索、记录、改克数、当天汇总、历史日历、体重、运动、导出 CSV/JSON 全部可用。
- 直接双击 index.html（file://）打开：全部功能可用，但浏览器通常不给摄像头权限，扫码请用「手动输入条码 / 手动填营养表」；IndexedDB 图片仍可用。
- 没有后端服务器，所以：没有账号登录、没有云同步、没有自动抓取新食物。食谱与建议都在本地计算完成。
- 离线缓存（Service Worker）只在 https 下注册；file:// 打开时不会注册，但应用照常运行。
- 数据只在本机：换手机、清缓存、换浏览器或换域名都会丢，请每月导出一次 JSON 备份。

五、数据与备份
- 记录、体重、目标、自建食物存 localStorage（约 5MB，按每天十几条估算可存 3–5 年）。
- 扫码包装图存 IndexedDB，单张压缩到长边约 400px、≤100KB；默认导出不含图片。
- 导出 CSV 采用 UTF-8 带 BOM，Excel 可直接打开，含日期列。
- 导入 JSON 会覆盖当前记录，但会把本机已有的自建/扫码条目按条码或名称合并回来，避免丢条目；导入前建议先导出一份。
